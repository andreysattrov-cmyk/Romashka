# Ромашка Premium

Готовый сайт цветочного магазина:
- современный каталог;
- отдельная страница каждого букета;
- описание, состав и размер;
- заказ через WhatsApp с готовым текстом;
- адаптивный дизайн;
- рабочая админ-панель;
- добавление, редактирование и удаление товаров;
- загрузка JPG/PNG/WEBP;
- сохранение каталога в data/products.json.

## Запуск

```bash
npm install
npm run dev
```

Сайт:
http://localhost:3000

Админ:
http://localhost:3000/admin.html

Логин:
admin

Пароль:
admin123

## Перед передачей клиенту

Открой server.js и замени:

const WHATSAPP_NUMBER = '992900000000';

на настоящий номер WhatsApp в международном формате без `+`, пробелов и скобок.

Например:
const WHATSAPP_NUMBER = '992901234567';

После изменения перезапусти сервер.
